# expense-tracker-python
A simple beginner-friendly Expense Tracker built with Python to calculate total expenses.

About the Project

The Expense Tracker is a beginner-level Python project that allows users to enter multiple expense amounts and calculate their total spending.

The user can continue entering expenses and type done when they have finished. The program then displays the total amount spent.

Features
Enter multiple expenses
Automatically calculate total expenses
Type done to finish entering expenses
Display the total amount spent
Simple beginner-friendly Python code
Technologies Used
Python
Variables
while loop
User Input
float() type conversion
Basic arithmetic
Conditional statements
How It Works

The program starts with the total expense set to zero.

The user enters an expense amount:

Enter expense amount (or 'done' to finish):

Each amount is converted into a number and added to the running total.

When the user enters:

done

the program stops accepting expenses and displays the total spent.

Example
Enter expense amount (or 'done' to finish): 500
Enter expense amount (or 'done' to finish): 250
Enter expense amount (or 'done' to finish): 150
Enter expense amount (or 'done' to finish): done

Total Spent: 900.0
